# GridGuard AI

## AI Grid Copilot

Forecast → Explain → Decide → Simulate → Prevent

GridGuard AI is a decision-support platform for grid operators.

The system predicts feeder-level demand, identifies future overload risk,
explains the risk, evaluates flexible resources, and recommends an
intervention before the overload occurs.
